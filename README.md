# 🌦 Weather App

A beginner-friendly web-based weather app that fetches live weather data for any city using the **OpenWeatherMap API**.

## 🧠 Skills Practiced
- HTML for structure
- CSS for layout and design
- JavaScript for interactivity and API handling
- Fetching live data from a public API

## 🚀 Features
- Search for weather by city name
- Display temperature, description, and weather icon
- Responsive and glass-effect UI
- Error handling for invalid inputs or API issues

## 🛠 Technologies Used
HTML | CSS | JavaScript | OpenWeatherMap API

## 📦 How to Run
1. Get your API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Replace `YOUR_API_KEY_HERE` in `script.js`
3. Open `index.html` in your browser
